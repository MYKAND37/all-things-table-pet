# All Things Table Pet

把桌宠做成一个**平台**，而不是一个会动的图片。

## 这个项目想做什么

核心不是"再加一个角色"，而是让**用户自己造**：

| 方向 | 用户能做什么 |
|---|---|
| **部件化角色** | 不画整只角色，而是**画一个部位传一个**（一只手臂、一条腿），系统拼装成角色 |
| **可视化逻辑** | 不写代码，用搭积木的方式定义「**触发事件 → 判断条件 → 做出反应**」 |
| **道具系统** | 自定义道具，并让道具和角色产生互动 |

所以它更像一个**桌宠版的 Scratch**：引擎是通用的，内容是用户产出的。

## 架构方向（还没开工）

```
事件系统        谁在什么时候发生了什么
    ↓
规则 / 脚本层   用户搭的逻辑：什么条件 → 做什么
    ↓
实体层          角色、道具，都是实体
    ↓
表现层          骨骼、图层、动画 —— 负责"怎么画出来"
```

骨骼只是**最底下的一个子系统**，不是核心。

## 构建

CI 在 push 到 `main` 时自动出 debug APK（GitHub Actions → Artifacts）。

本地构建需要 JDK 17 + Android SDK：

```bash
gradle assembleDebug
```
