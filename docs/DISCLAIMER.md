## 2. 你能拿它做什么（许可状态）

**这个仓库目前没有 `LICENSE` 文件**，也就是默认**保留所有权利**。GitHub 的服务条款允许你
查看和 fork，但"自己打包一个 APK 发给别人"这件事，严格讲需要作者同意。

这是个**待决定的问题**，而不是一句免责能解决的：

| 你想要的效果 | 该做的事 |
|---|---|
| 别人可以自由使用、修改、再分发（含商用） | 加一个宽松许可证（MIT / Apache-2.0），并在里面说清**素材**的归属 |
| 只允许自己玩、自己打包自用 | 保持保留所有权利，但在 README 里写明"个人自用可以，分发请先联系" |
| 允许打包分发，但不许闭源改名卖 | 用 GPL-3.0 / AGPL-3.0 这类传染性许可证 |

（在你决定之前，这一节就把现状说清楚：**没有许可证 = 默认不许再分发**。）

## 5. `.atppet`：最难的一块，因为它是你的内容

`.atppet` 是一个压缩包，装的是**你**的骨架、部位图、动作、规则、粒子、液体。它可以被导入

代码多得多：

## 6. 隐私

关于这个应用对你做了什么，这部分可以写得很硬：

- **它没有联网权限**：`AndroidManifest.xml` 里没有任何网络权限（只有悬浮窗、前台服务、
  通知这三样），代码里也没有一处网络调用。**你的东西不会离开这台手机**；
- **它不读屏幕**：悬浮桌宠只是"画在别的应用上面"，不截屏、不录屏、不监听你的输入；
- **它不收集统计**：没有账号、没有埋点、没有崩溃上报；
- **数据都在应用自己的目录里**：角色、规则、动作、动画 —— 删掉应用就等于全部删除；
- 唯一写到公共位置的是**调参诊断 CSV**（你自己按"导出诊断"才会产生），内容是抖动的数值，
  没有个人信息。

## 10. 应用里那道门

**第一次打开这个应用，它会先把这一份摆在你面前**，两条路：同意 → 进应用；不同意 → 退出。
几条刻意的规矩：

- **同意之前应用什么都不做**：连"把出厂角色铺到硬盘上"都排在门后面 —— 不是洁癖，
  "同意"这两个字就是这个意思；
- **关不掉**：返回键、点对话框外面都不行（`setCancelable(false)`）。要同意就同意，要不同意
  就退出，没有第三种状态；对话框被系统收走而人还没选，算没同意；
- **记住的是版本号**：`Settings.DISCLAIMER_VERSION`。**改了上面这些内容就把那个数加一**，
  应用会重新问一次 —— 一份签过一次、内容却变过的同意书，不是同意书；
- 设置里有一处「重新阅读免责声明」，随时能再看一遍（也写着当前同意的是第几版）。

手机上那一段是这里的**摘要**（AI 开发 / 包的责任 / 内容红线 / 不要分享包 / 隐私 + 全文地址），
